## Автоматизированный скрипт развёртывания Hive с внешним PostgreSQL

### Инструкция по использованию

1. Сохраните скрипт как `deploy_hive.sh` на узле **NameNode (192.168.10.19)**.
2.
   ```bash
   chmod +x deploy_hive.sh
   ```
3.
   ```bash
   ./deploy_hive.sh
   ```

### Что делает скрипт

- На `dn01`:
  - Устанавливает PostgreSQL 16, если не установлен.
  - Создаёт базу данных `metastore` и пользователя `hive`.
  - Настраивает `postgresql.conf` для прослушивания IP-адреса `dn01`.
  - Добавляет правила в `pg_hba.conf` для доступа с `nn` и `jn`.
  - Перезапускает PostgreSQL.
- На `nn`:
  - Скачивает и распаковывает Hive (если ещё не установлен).
  - Добавляет переменные окружения в `~/.profile`.
  - Создаёт `hive-site.xml` с параметрами подключения к PostgreSQL.
  - Загружает JDBC-драйвер PostgreSQL в `lib/`.
  - Создаёт необходимые каталоги в HDFS и устанавливает права.
  - Инициализирует схему метастор (если не инициализирована).
  - Запускает HiveServer2 в фоне.
- Проверяет открытые порты и выводит информацию для подключения.
