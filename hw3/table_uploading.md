# Пример автоматизированной загрузки данных в партиционированную таблицу Hive

Скрипт загружает CSV-файл из HDFS в конкретную партицию таблицы, что позволяет легко автоматизировать процесс (например, по расписанию).

## 1. Создание партиционированной таблицы

Подключитесь к Hive (через beeline) и выполните:

```sql
CREATE TABLE sales (
    product_id INT,
    amount DOUBLE
)
PARTITIONED BY (sale_date STRING)
ROW FORMAT DELIMITED
FIELDS TERMINATED BY ','
STORED AS TEXTFILE;
```

Таблица будет храниться в `/user/hive/warehouse/sales`.
Партиции будут подкаталогами вида `sale_date=YYYY-MM-DD`.

## 2. Подготовка данных и загрузка в HDFS

Создайте тестовый CSV-файл, например `data_2025-03-11.csv`, со следующим содержимым:

```csv
101,250.5
102,300.0
103,150.75
104,420.0
105,75.2
```

Загрузите его в HDFS в каталог, откуда скрипт будет его брать (например, `/user/hadoop/sales_data/`):

```bash
hdfs dfs -mkdir -p /user/hadoop/sales_data
hdfs dfs -put ~/data_2025-03-11.csv /user/hadoop/sales_data/
```

## 3. Скрипт автоматической загрузки `load_sales.sh`

Сохраните следующий скрипт на узле `nn` (например, в `/home/hadoop/load_sales.sh`) и сделайте его исполняемым (`chmod +x load_sales.sh`).

## 4. Запуск скрипта

```bash
./load_sales.sh 2025-03-11
```

## 5. Проверка результата

```bash
beeline -u jdbc:hive2://nn:5433 -n hadoop -e "SELECT * FROM sales WHERE sale_date='2025-03-11';"
```

Ожидаемый вывод:

```
+------------+----------+-------------+
| product_id | amount   | sale_date   |
+------------+----------+-------------+
| 101        | 250.5    | 2025-03-11  |
| 102        | 300.0    | 2025-03-11  |
| 103        | 150.75   | 2025-03-11  |
| 104        | 420.0    | 2025-03-11  |
| 105        | 75.2     | 2025-03-11  |
+------------+----------+-------------+
```
